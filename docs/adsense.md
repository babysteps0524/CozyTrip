# Google AdSense 설정 가이드

이 문서는 CozyTrip 프로젝트의 Google AdSense 승인 전·후 설정과 광고 슬롯 구성 가이드입니다. AGENT.md §9(Google AdSense design)을 따릅니다.

> **중요:** AdSense 승인과 수익은 보장될 수 없습니다. 승인 전에는 광고가 활성화된 것처럼 표현하지 않습니다.

## 1. 승인 전 확인 사항

AdSense를 활성화하기 전에 현재 공식 정책을 확인하고 확인 날짜와 링크를 기록합니다:

- [ ] 사이트 콘텐츠와 가치 기준 (고유한 유용한 콘텐츠 충분한지)
- [ ] 게시자 정책 준수 여부
- [ ] 광고 배치 및 클릭 유도 금지 규정
- [ ] 개인정보 및 동의 요구 사항
- [ ] 쿠키 및 광고 개인화 관련 설명
- [ ] `ads.txt` 요구사항과 설정
- [ ] 사이트 검토 절차
- [ ] 광고 코드와 자동 광고/수동 광고의 차이
- [ ] 모바일 화면에서의 광고 배치
- [ ] 광고가 내비게이션/콘텐츠와 혼동되지 않는지

## 2. 환경변수

광고 클라이언트 ID와 슬롯 ID는 환경변수로 설정합니다. `.env.example`에 변수 이름과 설명만 제공합니다.

| 변수                          | 범위 | 설명                |
| ----------------------------- | ---- | ------------------- |
| `PUBLIC_ADSENSE_CLIENT`       | 공개 | AdSense 게시자 ID   |
| `PUBLIC_ADSENSE_SLOT_HOME`    | 공개 | 홈 광고 슬롯 ID     |
| `PUBLIC_ADSENSE_SLOT_ARTICLE` | 공개 | 콘텐츠 광고 슬롯 ID |

환경변수가 없을 때 사이트가 오류를 내지 않도록 안전하게 처리합니다. AdSlot 컴포넌트는 환경변수 부재 시 플레이스홀더를 표시합니다.

## 3. 광고 컴포넌트 (`AdSlot`)

`src/components/AdSlot.astro`는 재사용 가능한 광고 슬롯입니다.

### 3.1 동작

- 환경변수(`PUBLIC_ADSENSE_CLIENT` 및 해당 슬롯 ID)가 모두 설정되어 있을 때만 실제 광고 태그를 렌더링합니다.
- 환경변수가 없으면 광고 자리 안내 플레이스홀더를 표시하며, 광고가 정상 표시된 것으로 보고하지 않습니다.
- 광고 슬롯은 명확히 "ADVERTISEMENT"로 라벨링되어 편집 콘텐츠와 시각적으로 구분됩니다.

### 3.2 광고 위치 후보

- 콘텐츠 목록 사이의 중간 광고
- 긴 가이드 본문 내 적절한 구간
- 호텔 상세 콘텐츠의 본문과 시각적으로 분리된 영역
- 필요 시 데스크톱에서만 사이드바

## 4. 광고 UX 제한

- 광고를 콘텐츠나 예약 버튼처럼 위장하지 않습니다.
- 광고 클릭을 요청하거나 클릭을 유도하지 않습니다.
- 콘텐츠보다 광고가 페이지를 압도하지 않도록 합니다.
- 레이아웃 이동(CLS)을 줄이기 위해 광고 컨테이너 공간을 확보합니다.
- 모바일 화면을 가리는 임의의 고정 광고를 만들지 않습니다.
- 광고가 없는 경우 빈 공간을 과도하게 남기지 않습니다.

## 5. 개인정보 및 동의

- 방문자 지역 및 실제 광고 설정에 맞춰 개인정보 처리방침과 동의 요건을 확인합니다.
- 실제 수집하지 않는 개인정보를 수집한다고 쓰지 않습니다. 실제 기능과 개인정보 고지를 일치시킵니다.
- 광고 클릭과 예약 전환을 혼동하는 추적 로직을 만들지 않습니다.

## 6. 체크리스트

AdSense 승인 후 운영:

- [ ] `PUBLIC_ADSENSE_CLIENT`, `PUBLIC_ADSENSE_SLOT_HOME`, `PUBLIC_ADSENSE_SLOT_ARTICLE` 환경변수 설정
- [ ] `ads.txt` 설정 (필요한 경우)
- [ ] 개인정보처리방침에 광고/추적 기술 관련 내용 추가
- [ ] 광고 슬롯이 편집 콘텐츠와 명확히 구분되는지 시각 검토
- [ ] 모바일·데스크톱에서 광고가 콘텐츠를 가리지 않는지 검토
- [ ] CLS(레이아웃 이동) 최소화 확인
