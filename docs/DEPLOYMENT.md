# 배포 체크리스트 (Cloudflare Pages 후보)

이 문서는 배포 안내이며 실제 배포를 수행하지 않습니다.

1. 실제 공개할 도메인과 브랜드를 확정합니다. 현재 도메인 `cozytrip.kr`을 변경하거나 기존 사이트를 교체하지 않습니다.
2. 새 프로젝트만 별도 저장소 또는 격리된 하위 디렉터리에서 빌드되도록 구성합니다.
3. 빌드 명령은 `bun run build`, 출력 디렉터리는 `dist`입니다.
4. Cloudflare가 지원하는 Bun 버전을 확인하고 `BUN_VERSION`을 프로젝트 환경에 맞게 설정합니다.
5. 광고/제휴 계정이 승인된 후 실제 환경변수를 등록합니다. 비밀키를 `PUBLIC_` 변수로 만들지 않습니다.
6. Preview 배포에서 링크, 모바일 레이아웃, 다크 모드, 접근성, 메타데이터, 광고 영역, 개인정보 고지를 확인합니다.
7. `robots.txt`, 사이트맵, canonical, 404 페이지를 확인합니다.
8. 이미지의 이용 권리와 외부 이미지의 안정성을 검토합니다.
9. 운영자의 명시적 승인 없이 프로덕션 배포, DNS 변경, 기존 사이트 교체를 하지 않습니다.
