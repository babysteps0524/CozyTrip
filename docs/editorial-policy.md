# 편집 및 사실 검증 정책

이 문서는 CozyTrip의 콘텐츠 출처, 검증 상태, 수정 원칙을 정의합니다. AGENT.md §7, §8, §10을 따릅니다.

## 1. 출처 우선순위

사실 주장의 출처는 다음 우선순위를 따릅니다:

1. **호텔·시설의 공식 웹사이트와 공식 공지**
2. **공식 교통 운영자 및 관광 기관의 안내**
3. **권한과 이용 조건을 확인한 예약·제휴 플랫폼 데이터**
4. **추가 검증이 가능한 신뢰할 수 있는 2차 출처**

URL만 붙여 두지 말고, 출처가 어떤 사실을 뒷받침하는지 기록합니다. 웹페이지의 존재가 재사용 권한을 뜻하지 않습니다.

## 2. 사실 확인 원칙

- 검증되지 않은 호텔 정보, 가격, 객실 재고, 평점, 리뷰 수, 예약 가능 여부, 이동 시간을 사실처럼 제시하지 않습니다.
- 검색 결과에 나온 내용만으로 확인이 끝났다고 가정하지 않습니다.
- 사실과 편집적 설명, 추론, 사용자 입력을 명확히 구분합니다.
- 데이터가 없으면 `unknown`, `unverified`, `needs_review` 같은 명시적 상태를 사용합니다.
- 출처가 없거나 충돌하는 값은 추정해 채우지 말고 `needs-verification`으로 표시합니다.
- 기계 생성 콘텐츠는 사람이 검토하고 승인하기 전에는 자동 발행하지 않습니다.

## 3. 이미지와 저작권

- 이미지는 사용 허가와 라이선스 조건을 확인한 자료만 운영 콘텐츠에 사용합니다.
- 원격 이미지 URL이 존재한다고 사용 권한이 보장되는 것은 아닙니다.
- 이미지 사용 권한, 출처, 대체 텍스트를 확인합니다.
- 외부 웹사이트의 문장, 사진, 로고, 리뷰를 허가 없이 복제하지 않습니다.
- 권리가 확인되지 않은 이미지는 공개 빌드에서 제외하거나 안전한 플레이스홀더로 교체합니다.

## 4. 제휴 및 광고 고지

- 제휴 링크는 실제 발급받은 링크만 사용합니다. 데모 링크를 실제 예약 링크처럼 제시하지 않습니다.
- 링크 주변에 사용자가 이해할 수 있는 제휴 관계 고지를 제공합니다.
- 링크가 정상 작동하는지, 추적 규칙과 리디렉션 정책을 확인합니다.
- 광고·제휴 링크가 편집적 판단을 왜곡하지 않도록 편집 정책을 유지합니다.
- 수익화가 콘텐츠의 정확성과 사용자 신뢰보다 우선하지 않도록 합니다.

## 5. AI 콘텐츠 사용

- AI는 구조화된 자료를 요약하고, 초안을 만들고, 누락 항목을 찾는 데 사용합니다. AI 출력은 자동으로 사실이 되지 않습니다.
- 자동 생성 글에는 검토 상태를 부여하고, 필수 검증이 끝나지 않은 글은 게시할 수 없게 합니다.
- 실제 투숙 경험이 없는 경우 직접 숙박한 것처럼 쓰지 않습니다. "실제 투숙 후기", "직접 경험", "현장 방문" 등의 표현은 검증 가능한 경험이 있을 때만 사용합니다.
- 과장 광고나 무근거 최상급 표현 ("최고", "완벽한", "무조건 추천" 등)을 피합니다.
- 같은 템플릿의 문장을 호텔마다 그대로 반복하지 않습니다.

## 6. 검증 상태와 게시 조건

| 검증 항목 | 게시 전 확인 사항 |
|-----------|------------------|
| 출처 | 공식 웹사이트, 공식 교통 기관, 관광청 등 우선 출처 사용 |
| 확인 날짜 | 출처 URL과 확인 날짜를 내부 데이터에 보존 |
| 이미지 권리 | `owned`, `licensed`, `approved_feed` 중 하나여야 함 |
| 제휴 링크 | 실제 발급받은 링크만 사용, 고지 필수 |
| 가격/재고/평점 | 승인된 최신 데이터가 있을 때만 사용 |
| 중복성 | 다른 글과 유사한 문구, 얇은 콘텐츠, 키워드 반복 검토 |

## 7. 게시 차단 조건

다음 조건 중 하나라도 충족하면 공개할 수 없습니다:

- 출처가 없는 중요 사실
- 확인 날짜가 없는 변동 정보
- 사용 권한을 확인하지 못한 이미지
- 실제 계정 승인 상태를 확인하지 못한 제휴 링크
- 가격/재고/평점을 실시간으로 검증하지 못한 경우
- 개인정보/광고 고지가 실제 구현과 다른 경우
- 자동 생성 콘텐츠가 독자에게 고유한 가치를 제공하지 못하는 경우

## 8. 오류 제보와 수정

공개 전 운영자가 관리하는 연락처를 `/contact/` 페이지에 추가해야 합니다. 오류 제보가 들어오면 해당 정보의 출처와 확인 날짜를 재검토하고, 확인이 끝날 때까지 중요한 주장은 보류합니다.

이 정책은 실제 운영 절차와 담당자가 정해지면 그에 맞게 업데이트해야 합니다. 법률 자문을 받은 것처럼 표현하지 않으며, 실제 운영 국가, 사용 기술, 광고 플랫폼 정책에 맞게 운영자가 최종 검토해야 합니다.
