# 기술 결정 기록

## 정적 생성

호텔과 여행 가이드는 읽기 중심 콘텐츠이므로 Astro SSG를 선택했습니다. 동적 검색은 빌드 시 데이터로 브라우저 내에서 필터링하며 서버 API를 가정하지 않습니다.

## 스타일링

UnoCSS Attributify와 `presetWind4({ dark: 'media' })`를 기본으로 사용합니다. `src/styles/uno.css`의 `@unocss` 지시문으로 유틸리티를 생성하며 일반 CSS 스타일시트를 추가하지 않습니다. 일부 서드파티 스크립트가 요구하는 속성은 해당 통합 요구사항을 확인해 최소화합니다.

## 콘텐츠 상태

정적 예시 호텔은 편집 후보로 명시되어 있으며 가격, 별점, 리뷰 수, 객실 재고를 제시하지 않습니다. 콘텐츠 생성 CLI는 Markdown 검토 초안만 생성합니다.

## 제휴·광고

실제 계정 승인과 공식 API 문서를 확인하기 전까지 제휴 URL/API 통합을 가짜로 구현하지 않습니다. 광고 슬롯은 실제 환경변수가 있을 때만 광고 태그를 렌더링합니다.

## 공개 도메인

설정상 canonical 기본 도메인은 `https://cozytrip.kr`입니다. 호텔 콘텐츠와 기존 도메인 브랜드 사이에 주제 불일치가 있을 수 있으므로, 공개 전에 운영자가 도메인 전략을 확정해야 합니다.
