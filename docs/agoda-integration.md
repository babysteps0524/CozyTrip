# Agoda 어필리에이트 API 연동 가이드

이 문서는 CozyTrip 프로젝트의 Agoda Affiliate Lite API 연동 전제 조건, 보안 규칙, 제한사항을 정의합니다. AGENT.md §6(Agoda API and affiliate integration)을 따릅니다.

> **중요:** 실제 계정 승인과 공식 API 문서 확인 이전에는 API 연동을 "완료"라고 주장하지 않습니다. 이 문서는 연동 지점과 수동 대체 경로, 설정 문서만 제공합니다.

## 1. 연동 전 확인 사항

아래 항목을 모두 확인한 후 `docs/agoda-integration.md`에 기록합니다:

- [ ] 아고다 어필리에이트 프로그램 계정이 승인되었는가?
- [ ] 현재 사용 가능한 프로그램/제품이 무엇인가?
- [ ] Affiliate Lite API에 대한 실제 접근 권한이 있는가?
- [ ] 공식 최신 문서와 버전은 무엇인가?
- [ ] 인증 방식과 API 키의 범위는 무엇인가?
- [ ] 호텔 검색과 호텔 상세 데이터의 권한 범위는 무엇인가?
- [ ] 딥링크 생성 방식은 무엇인가?
- [ ] 이미지 사용 권한과 표시 조건은 무엇인가?
- [ ] 가격/재고 데이터 사용에 대한 제한은 무엇인가?
- [ ] 캐싱/갱신/요청 제한이 있는가?
- [ ] 링크의 제휴 식별자와 추적 방식은 무엇인가?
- [ ] 콘텐츠 또는 광고 표시와 관련한 필수 고지 조건은 무엇인가?
- [ ] 승인된 도메인/사이트가 지정되어야 하는가?

## 2. API 구현 규칙

### 2.1 엔드포인트와 인증

- API 엔드포인트와 요청/응답 필드는 실제 공식 문서 또는 성공적으로 검증한 응답에 근거합니다. 추측하지 않습니다.
- API 클라이언트는 `src/scripts/agoda-client.ts`에 격리되어 있으며, UI 코드와 분리됩니다.
- 타입과 런타임 스키마는 실제 문서에서 정의합니다.
- API 키/토큰은 서버 전용 환경변수(`AGODA_SITE_ID`, `AGODA_API_KEY`, `AGODA_API_SECRET`)에만 보관합니다.
- `PUBLIC_` 접두사를 붙여 브라우저에 노출하지 않습니다.
- 비밀 번들을 공개 환경변수, 소스 제어, 로그에 포함하지 않습니다.

### 2.2 오류 처리

- 타임아웃, 네트워크 오류, 4xx/5xx 응답, 빈 결과, 속도 제한을 처리합니다.
- 적절한 실패에만 재시도하며, 지수 백오프를 적용합니다.
- 실패 시 빈 호텔 데이터나 가짜 예약 링크를 만들어 내지 않습니다.
- API가 제공하지 않는 정보는 만들어 내지 않습니다.

### 2.3 이미지 및 콘텐츠 사용

- 반환된 이미지 URL은 자동으로 다운로드, 재호스팅, 수정, 영구 저장 권한을 부여하지 않습니다.
- API의 이미지 사용 조건을 위반하는 장기 캐싱을 하지 않습니다.
- 이미지 출처, 권리 상태, 크레딧을 데이터로 관리합니다.

### 2.4 모크 모드 및 드라이런

실제 API 접근이 확인되지 않았을 때:

- `src/scripts/sync-agoda-hotels.ts`의 `--mock` 옵션으로 모크 호텔 데이터를 사용합니다.
- `--dry-run` 옵션으로 파일 생성 없이 파이프라인 동작을 시뮬레이션합니다.
- 테스트 데이터는 `sample` 또는 `mock`으로 라벨링되어 검증된 라이브 데이터와 혼동되지 않도록 합니다.

## 3. 환경변수

`.env.example`은 변수 이름과 설명만 제공하며 실제 값은 포함하지 않습니다.

| 변수                         | 범위      | 설명                      |
| ---------------------------- | --------- | ------------------------- |
| `AGODA_SITE_ID`              | 서버 전용 | 아고다 제휴 사이트 ID     |
| `AGODA_API_KEY`              | 서버 전용 | 아고다 제휴 API 키        |
| `AGODA_API_SECRET`           | 서버 전용 | 아고다 API 비밀           |
| `PUBLIC_AGODA_AFFILIATE_URL` | 공개      | 제휴 링크 기본 URL (선택) |

`.env` 파일과 실제 API 키, 토큰, 개인 데이터는 Git에 커밋하지 않습니다.

## 4. 호텔 데이터 import 및 갱신

- import는 실제로 노출된 필드만 사용합니다 (식별자, 이름, 주소, 위치, 편의시설, 이미지, 제휴 URL 등).
- 필드별 출처와 마지막 확인 정보를 보존합니다.
- 공식 property ID를 중복 제거에 사용하고, 그렇지 않으면 검증 가능한 키로 가능한 중복을 플래그합니다.
- API 응답으로 편집자가 작성한 설명을 무조건 덮어쓰지 않습니다.
- 삭제, 비활성화, 누락된 필드를 안전하게 처리하고 변경 사항을 추적합니다.
- API 비용, 속도 제한, 허용 캐시 기간을 존중합니다.

## 5. 제휴 링크 전략

- 공식적으로 허용된 딥링크/호텔 링크 생성 방식을 사용합니다.
- 호텔 이름만으로 임의의 URL을 조합해 올바른 호텔 페이지라고 가정하지 않습니다.
- URL을 생성했다면 대상 URL, 생성 방법, 확인 날짜, 상태를 기록합니다.
- 링크 검사 도구는 추적 매개변수와 제휴 ID를 제거하거나 변경하지 않습니다.
- 사용자에게 링크가 제휴 관계임을 알아보기 쉽게 표시합니다.

## 6. 제한사항

아고다 API 접근 권한이 확인되지 않은 경우:

- 어댑터 인터페이스와 모크 픽스처만 제공합니다.
- 환경변수 예시와 설정 문서만 제공합니다.
- 테스트를 제공합니다.
- "통합 완료"라고 주장하지 않습니다.
